Вариант 13. Фитнес-центр

В папке размещены пять самостоятельных исходных файлов для выполнения контрольной работы:
- task_1.csv — данные для задания 1;
- task_2.csv — данные для задания 2;
- task_3.csv — данные для задания 3;
- task_4.csv — данные для задания 4;
- task_5.csv — данные для задания 5.

Все CSV-файлы сохранены в кодировке UTF-8-SIG. Разделитель столбцов — запятая. Десятичный разделитель в числовых значениях — точка.

Исходные файлы не редактируются вручную и не пересохраняются в табличном редакторе. Все чтение, проверка, преобразования и формирование производных файлов выполняются программно на языке Python.

Для просмотра структуры файла рекомендуется использовать текстовый редактор, среду разработки, Jupyter Notebook или Google Colab. При открытии CSV в табличном редакторе отдельные значения могут отображаться иначе из-за автоматического определения форматов; это не является основанием для ручного изменения исходных файлов.
